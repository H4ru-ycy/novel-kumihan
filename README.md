# 小説原稿・組版メーカー

小説の原稿を書きながら、本の組版をプレビューできるWebツールです。ファイルは `index.html` の1つだけで、ブラウザで開けば動きます。

## できること
- 縦書き・横書きの切り替え
- 一段組み・二段組みの切り替え
- 原稿サイズ：A4 / B5 / A5 / B6 / A6（文庫）。縦長・横長も切り替えられます
- 字数×行数の指定（二段組みは1段あたり）
- 文字数制限と文字数カウンター。400字詰め原稿用紙に換算した枚数も表示
- ルビ `｜漢字《かんじ》`、傍点 `《《強調》》`、縦中横、簡単な禁則処理
- 印刷・PDF保存（原稿サイズそのままで出力）

本文と設定は、使っているブラウザに自動で保存されます。

## 公開方法（GitHub Pages）
1. このリポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます
